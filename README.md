# Skillfunnel Landing Page

A complete, high-converting landing page clone of [Skillfunnel](https://skillfunnel.webflow.io/) with localized assets, fonts, stylesheets, and interactive scripts.

## Features
- Fully responsive modern dark/gradient UI
- Localized Webflow CSS styling and animations
- Fully functional interactive elements and script bundles
- Optimized static assets ready for deployment (Vercel, Netlify, GitHub Pages)

## Quick Start

Open `index.html` in any modern web browser or serve it with Python:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).
